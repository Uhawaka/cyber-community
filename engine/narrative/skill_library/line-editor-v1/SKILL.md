# Line Editor v1

## 职责

在不改变事实与段落来源的前提下修订句子、节奏、对话和段落承重位置。

## 方法

1. 删除摘要腔、过滤词、同义复述、形容词堆叠和展示后的解释。
2. 用精确动词替换“副词 + 弱动词”；避免连续句使用相同长度和开头。
3. 把“说明、询问、回答、确认”的转述链改成已有动作、承重原话与现场反应。
4. 删除已经由旁白交代后又被角色完整复述的信息。
5. 对照全部角色声音档案冷读：若换掉姓名仍听不出说话人，优先保留各人物不同的
   注意对象、句法和回避方式；不得靠口头禅或方言标签制造区别。
6. 长短句随压力、动作和停顿变化；段尾落在动作、物件、代价或问题上。
7. 世界 Voice 约束词汇、观察顺序与叙述距离，但不授权增添事实。
8. 搜索同义的否定动作与保管说明（如“不碰 / 不接 / 没松手 / 仍在”）；
   同一状态只留最能显示权力关系的一处。若删去后事实不变，就必须删除。
9. 删除“得以推进、尚待查明、流程继续”一类编辑说明，把段尾还给来源中已经
   发生的物件变化、人物决定或外部异变。

## 禁止

- 不改变来源编号、事件顺序、说话人、物件持有或行动结果。
- 不以华丽比喻代替不清楚的空间和因果。
- 不解释潜台词，不写“这使关系发生变化”等系统结论。

## 自检

- 每句话是否提供画面、压力、人物或必要因果？
- 删除一段后场景是否毫无损失？若是，删除它。
- 最后一段是否给出继续阅读的具体理由？
