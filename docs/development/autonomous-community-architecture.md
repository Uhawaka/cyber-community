# 自主社区架构

## 运行主链

```text
社区作者源 -> 世界包编译与校验 -> 托管运行
  -> 时间与世界过程结算 -> 个人感知与认知检索
  -> 个人决策 -> 行动裁决 -> 原子事件提交
  -> 个人记忆与知识投影 -> 只读观察和评审
```

离线策略与模型策略共享世界、裁决和事件协议。模型只能提出自己的一次行动；
规则决定行动是否成立以及对物质、时间和社会关系的影响。世界和角色的长期变化
来自已提交事件，不来自文本中对预期结果的宣称。

## 世界与角色

- 世界由地点、通路、实体、库存、设备、持续过程及组织构成。活动有开始和实际结算；
  未完成的活动不会因为计划或模型预期而产生结果。
- 角色的 Soul、个人记忆、听闻、观察、推断、信念、关系、目标和计划相互区分。
  私有作者信息不进入其他人的上下文，听闻不自动成为事实。
- 知识及行动带有来源。决策上下文提供可引用来源清单；本人当前可见的知识声明
  编号可解析到其真实来源，其他角色、过期或未提供的声明不能借此获得访问权限。
- 自主计划支持有界步骤、依赖、条件、材料上限、失败分支和到期复查。
  计划不是事实，其他角色仍须自行决定是否接受。

## 持久化与恢复

事件日志采用追加提交，世界状态和个人认知可从历史重建。托管运行绑定世界内容
hash、引擎源码指纹、策略版本及预算；配置变化时拒绝续跑，不静默切换行为。
每次模型决策先记录请求，再记录响应，最后提交行动或拒绝。已记录的响应在恢复时
复用；请求已记录但响应未记录时，结果不确定，不自动重试。普通角色事件不能借用
期限时钟。只读观察和重放不调用模型。

当前只支持版本化社区世界；旧包编译分支、旧运行器与旧公开接口已退役。
改变版本时应创建新运行，不能覆盖原始历史。历史能否只读依赖当前世界与事件校验，
不保证旧格式可重放。

## 边界

任意自然语言到任意世界能力的通用编译尚未实现，当前使用注册动作和结构化意图。
借贷等扩展社会规则不是一期框架完成的前置条件。机制、模型行为、人物与剧情质量
分别评估；重放通过不能替代真人质量验收。
