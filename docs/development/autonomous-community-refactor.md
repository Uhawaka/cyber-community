# 自主社区开发方向

目标是让角色在持续运转的世界中依据自身经历和处境独立行动，自然产生互动与后果。
不以事件数、模型调用数或长篇输出代替人物和剧情质量。

## 优先顺序

1. 完成世界创建、个人认知、模型决策、行动裁决、世界结算、持久化和观察主链。
2. 修复真实运行暴露的通用机制缺陷，保持个人知识、世界事实及其他角色意愿隔离。
3. 以单世界有界样本验证机制与真实模型行为；未稳定前不扩大多 seed 长跑。
4. 机制稳定后进行角色、因果链和故事质量评审，再决定是否扩大长期模拟。
5. 借贷、租赁及更复杂治理等细则放在后续迭代，不阻塞主链。

## 验收原则

- 世界活动、物质、时间和社会后果必须真实结算，失败不能部分提交。
- 恢复不得重置 Tick 或预算、分叉历史或重试不确定的外部请求。
- 角色只使用本人可见的感知、记忆和知识；声明、传闻及计划都不等于事实。
- 离线机制测试、真实模型测试和独立人工质量评审分别记录。
- 正式 100 Tick 人物与剧情门禁通过前，不运行 1000 Tick 质量实验。
- 不维护旧作者格式或旧托管协议的兼容实现；实验及测试产物放在 `outputs/`。

当前实现和待办见[任务检查点](autonomous-community-tasks.md)。
