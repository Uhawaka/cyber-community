# Autonomous behavior v1：长期行为去重复

## 假设与方法

如果机会评分包含近期动作冷却，短计划只在完成或失效时重算，并以 BFS 最短路径推进目标，那么 20 tick 中仍会发生互动、移动和资源获取，同时连续同类、同目标行为受到明确上限。

固定 `echo-quay` 与 `black-pine-ridge` 当前编译内容，RNG seed 为 `3 / 17 / 29`，每次运行 20 tick。动作按事件的 `actor_id` 归组；“同类连续”按事件类型计算，“同目标连续”按事件类型与 `target_entity_id` 的组合计算。

## 改进前

- `echo-quay` 每次 40 个动作：dialogue 为 `26 / 26 / 21`，move 为 `3 / 3 / 4`，gather 为 `6 / 7 / 9`。
- `black-pine-ridge` 每次 60 个动作：dialogue 为 `17 / 18 / 18`，move 为 `20 / 21 / 19`，gather 均为 `5 / 5 / 6`。
- `echo-quay` 的交谈占比最高达到 65%，固定交谈基础分会在角色同处时反复胜出。
- 每种动作都提交 `PlanDelta`，所以短计划并不表达跨动作意图。

## 改进后

- `echo-quay` 每次 40 个动作：dialogue 为 `9 / 8 / 9`，move 为 `10 / 10 / 9`，gather 为 `8 / 8 / 9`。
- `black-pine-ridge` 每次 60 个动作：dialogue 均为 `11`，move 为 `23 / 24 / 23`，gather 为 `5 / 4 / 5`。
- 六次运行均有 dialogue、move 和 gather。
- 按角色计算，同类动作最大连续数为 2；同类且同目标的最大连续数为 1。
- 相同 seed 仍可确定性 replay；seed 只通过 0–6 分的稳定扰动打破接近候选，不压过计划与冷却。

## 机制结论

- 在可重放状态中保留最近 8 个动作，评分同时惩罚近期同类和同对象行为。
- 三元短计划记录终结动作、目标与目标地点。计划有效且未完成时保持不变；完成或资源耗尽、对象移动、路径不可达时才重算。
- 目标不在当前位置时，所有位于 BFS 最短路径首步的 passage 获得计划加分；并列路径仍由 seed 提供小幅分歧。
- 实现只依赖世界图、实体 id、需求与当前状态，不含世界专名。

判定：passed。
