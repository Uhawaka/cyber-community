# 世界包 probe 与安全门禁实验

## 假设

目录世界包只有在编译成功后，才能进入与玩家运行隔离的确定性 probe。固定的多 seed 探针应能验证重放、知识来源、地图、资源与共址约束，同时对作者输入实行 fail-closed 的结构和容量限制。

## 方法

- 对 `echo-quay` 与 `black-pine-ridge` 各运行 8 个固定 seed，预算 20 tick。
- 每个 seed 检查 replay 等价、记忆来源、地图引用、资源/库存非负、对话双方共址、必需/禁止事件。
- 比较历史 hash 多样性；对资源数量和通路耗时做单变量扰动，比较结构化事件链。
- 注入路径穿越、绝对路径、symlink 逃逸、超大/过深文本、未知字段、schema 外 effect/delta、超量/超长 memory seed。
- 将工具、路径和网络指令写进合法作者文本，确认其仅被编译为数据且不产生外部动作。

## 结果

- 两个世界包的 8 个 seed 均通过全部不变量，历史 hash 均达到 8/8 唯一。
- probe 使用内存事件日志；不创建、追加或登记玩家 run。用户门禁在 probe 中确定性 abstain 后继续执行预算。
- 资源量与通路耗时扰动均改变结构化事件链。
- 非法路径、symlink、容量、深度、未知字段和 schema 外执行形状均产生结构化诊断。
- 编译器不调用模型；提示式作者文本不授予工具、文件或网络能力。

判定：passed。
