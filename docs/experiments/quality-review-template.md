## 硬门禁

任一项失败则停止体验评分，并记录为无效运行：

- [ ] 所有状态变化来自合法 Event Log 追加
- [ ] 相同 revision、输入和 seed 可 replay
- [ ] Event、Projection 和持久化无半提交
- [ ] 角色与 Avatar 无知识、权限或资源越界
- [ ] Narrative 和模型没有创造或回写世界事实
- [ ] 预算、暂停和终止条件有效

## 系统质量评分

使用 0–4 级：0 缺失或破坏性失败；1 偶然成立；2 基本可用但脆弱；3 稳定达到目标；4 跨世界和长时段仍有充分证据。
