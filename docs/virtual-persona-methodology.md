# 虚拟人方法论 — 从市场研究/UX 领域借鉴
#
# 来源综合:
#   - Synthetic Users (OCEAN + 行为一致性)
#   - Jobs-to-be-Done 框架 (Clayton Christensen)
#   - Empathy Mapping (Dave Gray)
#   - Behavioral Personas (Alan Cooper)
#   - Mental Models (Indi Young)
#   - 认知偏差理论 (Kahneman/Tversky)
#
# 这些方法论的核心差异 vs 我们当前的角色模型:
#   当前: 角色有"人格"但缺乏"情境中的决策逻辑"
#   目标: 角色在特定情境中做出可信的选择，且选择随时间有一致性

# ═══════════════════════════════════════════════════════════════
# 1. Jobs-to-be-Done (JTBD) — 角色在"雇佣"什么
# ═══════════════════════════════════════════════════════════════
# 人不买产品，人"雇佣"产品来完成一项工作。
# 同理，角色不"做研究"——角色在试图完成一项更深层的工作。

jtbd_framework:
  description: >
    每个角色的行为背后有一个待完成的"工作"。
    不是"我在研究质数"——而是"我在试图证明我自己不是靠运气进来的"。
    
  functional_job:     # 功能性工作——要完成什么具体任务
  emotional_job:      # 情感性工作——想感受什么 (例: 想感受自己是有洞见的)
  social_job:         # 社会性工作——想在别人眼中成为什么 (例: 想让Yuki承认我)
  
  push_force:         # 推力——什么在推动他离开现状 (例: 对"不够好"的恐惧)
  pull_force:         # 拉力——什么在吸引他走向新状态 (例: "如果能证明这个...")
  anxieties:          # 焦虑——什么让他犹豫不敢行动
  habits:             # 习惯——什么让他维持现状不动

# ═══════════════════════════════════════════════════════════════
# 2. Empathy Mapping — 角色在情境中的完整感知
# ═══════════════════════════════════════════════════════════════

empathy_map:
  description: >
    不是"角色是什么"，而是"角色在特定时刻感知到什么"。
    这个映射让角色对同一事件产生不同反应——
    因为两个人看到/听到/感受到的东西不同。
    
  thinks:             # 在想什么（内心的独白，不会说出来的）
  feels:              # 感受到什么情绪
  sees:               # 看到什么（在环境中注意到什么）
  hears:              # 听到什么（别人说了什么，怎么理解的）
  says:               # 说出来什么（和 thinks 的差距就是真实性）
  does:               # 做了什么
  pains:              # 痛点——什么让他痛苦/挫败/焦虑
  gains:              # 收获——什么让他满足/兴奋/有成就感

# ═══════════════════════════════════════════════════════════════
# 3. Mental Models — 角色如何概念化世界
# ═══════════════════════════════════════════════════════════════

mental_models:
  description: >
    每个人对世界的运作方式有一套自己的理解。
    这不是"知识"，是"我认为世界是这样的"——
    即使它是错的，角色也按这个模型行动。
    
  examples:
    - model: "好的数学必须是美的——如果证明丑陋，说明方向错了"
      holder: Yuki
    - model: "如果我不能把它算出来，我就不相信它"
      holder: Elias
    - model: "物理直觉比数学严格性更接近真相——严格性是事后的包装"
      holder: Pavel

# ═══════════════════════════════════════════════════════════════
# 4. Cognitive Biases — 角色会系统性犯错
# ═══════════════════════════════════════════════════════════════

cognitive_biases:
  description: >
    真实的思考包含系统性的偏差。角色不应该总是"理性"的。
    他们应该有自己特有的认知盲区——这些盲区驱动了剧情。
    
  common_biases:
    - name: "确认偏误 (Confirmation Bias)"
      desc: "只看到支持自己理论的数据，忽视反面证据"
      example: "Elias 算了一百组数据支持他的模式，但忽略了五组不符合的数据"
    - name: "沉没成本 (Sunk Cost)"
      desc: "因为已经投入太多而不愿放弃"
      example: "Elias: '我已经花了十年在筛法上，不能现在换方向'"
    - name: "锚定效应 (Anchoring)"
      desc: "过度依赖第一个接触到的信息"
      example: "Pavel 的第一个湍流模型框架定义了他后来所有的研究方向"
    - name: "达克效应 (Dunning-Kruger)"
      desc: "在自己不擅长的领域高估能力"
      example: "Elias 对范畴论的轻视——'那不就是把已知的东西用更复杂的语言说一遍'"
    - name: "现状偏误 (Status Quo Bias)"
      desc: "倾向于维持现状即使改变有利"
      example: "Yuki: 明明知道需要学一些计算，但每次都推迟"

# ═══════════════════════════════════════════════════════════════
# 5. Behavioral Consistency — 选择不是随机的
# ═══════════════════════════════════════════════════════════════

behavioral_consistency:
  description: >
    虚拟人的核心可信度来源：在相同情境下做出相似选择。
    这不是"每次做同样的事"，而是"选择背后的决策逻辑一致"。
    
  decision_framework:
    step_1_recognize:    # 识别情境: "这是一个什么类型的时刻？"
    step_2_evaluate:     # 评估选项: "我有哪些选择？"
    step_3_filter:       # 过滤: 心理模型 + 认知偏差 → 缩小选项
    step_4_choose:       # 选择: 满足（satisficing），不是最优（optimizing）
    step_5_justify:      # 事后合理化: "我选这个是因为..."
    
  consistency_tests:
    - "如果同样的情境出现三次，角色会做同样的选择吗？至少有70%的一致性？"
    - "如果角色的核心信念被挑战，他的第一反应是什么？每次都一样吗？"
    - "角色什么时候会打破自己的模式？什么条件能触发？"
