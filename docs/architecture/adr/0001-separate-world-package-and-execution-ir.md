# ADR-0001：世界包与执行 IR 分离

- 状态：Accepted（目标架构）
- 日期：2026-10-17

## 决策

世界包是可编辑、可发布的作者资产；Execution IR 是编译器从一个确定 revision 生成的不可变运行输入。Runtime 只消费 IR，不直接解释布局、自然语言意图或编辑器状态。

IR 必须携带世界包标识、revision、schema/能力版本、依赖锁和内容 hash。编译不得调用模型补写缺失字段。

## 理由

作者格式需要易编辑和演进，运行格式需要确定、紧凑和可验证。混用会让 UI 布局影响回放，并使运行时偷偷承担创作决策。

## 输入、输出与失败

- 输入：一个世界包 revision 与可解析依赖。
- 输出：IR、内容 hash、诊断；有错误时不得输出可运行结果。
- 失败：未知类型、依赖缺失、引用或能力版本不兼容、规则无法编译。

## 后果

- 修改世界包必须生成新 revision，再 restart 或 fork。
- IR 可缓存，但不能反向成为作者源文件。
- capability 只有满足三次晋升原则后才进入通用 IR；实验字段留在包或 Workflow。

## 验收

1. 仅改变布局不改变语义 hash。
2. 同一 revision 与依赖锁重复编译得到等价 IR。
3. Runtime 不读取作者图布局或用模型补全字段。
