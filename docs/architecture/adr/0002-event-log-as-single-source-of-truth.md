# ADR-0002：Event Log 是唯一动态事实源

- 状态：Accepted（目标架构）
- 日期：2026-10-17

## 决策

一次运行中，只有成功追加到 append-only Event Log 的事件能改变动态事实。客观状态、知识、关系、位置、Memory、阶段和索引均从 Execution IR 与日志投影得到。

事件至少绑定 run、世界 revision/IR hash、前后状态版本、行动依据、可见性、Delta 与确定性种子。提交先在副本校验完整事件，再持久化并发布新投影。

## 理由

单一权威历史使 replay、fork、审计和故障恢复可验证，避免缓存、摘要或模型文本悄悄改写世界。

## 输入、输出与失败

- 输入：通过规则校验、状态版本连续的候选事件。
- 输出：持久化事件位置和可重建的新版本。
- 失败：旧版本、错误 run/IR、非法 Delta、序列断裂、持久化失败；均不得暴露半提交状态。

## 后果

- Projection 可删除重建，不独立接受业务写入。
- 世界包静态事实不复制为动态事件，除非 fork genesis 明确引用来源。
- 呈现正文、已读与通知元数据不进入 Event Log。

## 验收

1. 清空投影后可得到相同状态和可见知识。
2. 失败提交不改变日志长度或可见投影。
3. 任意动态事实可追溯到事件；摘要不能反向覆盖事件。
