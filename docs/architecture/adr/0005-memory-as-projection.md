# ADR-0005：Memory 是角色视角投影

- 状态：Accepted（目标架构）
- 日期：2026-10-17

## 决策

Memory 不是第二套历史，而是 `Execution IR + Event Log + actor_id + projection_version` 的派生读模型。每条记忆必须保留来源事件、角色可见性、解释与置信度；摘要可压缩表达，不能授予角色新知识。

核心作者记忆属于世界包静态设定；运行中形成的情节记忆来自事件投影。错误记忆或谎言也必须有角色获得该信念的来源事件，且不能覆盖客观事实。

## 理由

直接保存自由文本记忆会产生知识泄露、重复事实和 replay 漂移。来源化投影允许按角色重建、遗忘、排序和重新摘要。

## 输入、输出与失败

- 输入：角色 id、投影版本、可见事件、检索主题与预算。
- 输出：带 `source_event_ids`、相关度、置信度和可见性标签的 Memory 记录。
- 失败：未知角色、来源事件缺失、事件对角色不可见、投影版本不支持。

## 后果

- Memory 写入 API 实质上提交“观察/获知/形成信念”事件，而不是直接改缓存。
- 删除 Memory 索引后可以重建；模型摘要变化不改变角色实际已知事件集合。
- Creator 的全知 Memory 与 Avatar Memory 必须分别投影。

## 验收

1. 每条运行时 Memory 至少引用一个角色可见的来源事件。
2. 清空并重建后，角色已知事件集合一致。
3. 摘要包含不可见事实时校验失败，且不会进入后续 Perception。
