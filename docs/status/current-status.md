# 当前进度与后续重点

更新时间：2026-10-18

## 1. 当前判断

项目已经完成“目录世界包能够被安全编译、持续运行、重放、持久化、接受用户参与并生成来源化文字”的技术纵切。它证明了架构方向可行，但尚未证明能够稳定生成值得长期追更的剧情；最新文学质量循环的最佳盲评为 62/80，未达到 64/80 退出线。

当前阶段应定义为：**配置驱动体验契约与实体场景纵切已建立，世界行为与文学
质量仍在闭环验证。** 设计蓝图在 `docs/design.md`。

2026-10-18 的机制已经接到代码里，后续开发按这些边界继续，不要退回事件配额或动作枚举：

- 角色这一手是 think / address / act。想和说不请环境。提示词把志向、行事方式和眼前这一手分开，场景问题只是这一处的限度。
- 章节由 `engine/narrative/division.py` 按内容和离开处收束。`episode_overrides` 仍校验，但不切章。双方原话由 `exchange.py` 装配。
- 离开当前地点只能落到相邻通路。跳过通路的转移会被拒绝。这一层还没有别人回答时，不会把“离开”自动补成旅行。
- 黑松岭把征供链按地点分层。seed 83 的新目录 `outputs/longform/black-pine-ridge-seed83-hand/` 在 8 个 tick 里走到后门、破庙、林间和征供废驿，三人都到了废驿，回退为 0。历史 `c62764ffc73bfaa032aeec35b5dac3875465b4c7dfb40c39c79e6eab118193f5`。这不证明文字已经成立。记录见 `docs/experiments/2026-10-18-dispersed-levy-chain.md`。

### 实体场景运行

- World → Location → Scene instance → typed Entity Component 的层级；
- 地点可声明多个 scene seed，场景按剧情需要首次懒渲染并事件化持久化；
- 场景重访不重新随机，本地时钟、最近公共回合和外部异变持续演化；
- 完整角色只读取第一人称感知并提交自由意图，不依赖动作枚举；
- 世界裁决器提交通用组件补丁、唯一物件持有、交互请求与 scene transition；
- 多角色请求/回应与轻量 NPC；事件 codec、replay、fork 均覆盖 Scene/Turn；
- 黑松岭 `evolution` 已切到 `scene_turns`，不再经过 legacy Planner/ActionKind。
- 场景收束后，角色按目标在 authored passage 图上寻找最近未决场景；已收束地点
  可以作为过境节点但不会再次充当剧情目的地，地图位置与 Presence 原子同步；
- 可恢复长篇 CLI 已支持按章节目标分段运行、周期发布、UserGate 选择、故事文档
  输出和探索/反循环/连续性/replay 门禁；
- 角色意图按 think / address / act 调度：思考只写自己，提到物件也不会升级成
  环境裁决；对白当场加载被点名的对象并提交双方原话，环境裁决只在 `act` 时加载。
  还在等同一个人回答时，换一种说法追问记为无进展。同一人重复已经做过的决定不进正文。
  这个问题还开着、且这一手没有决定时不能离开。写明地点的事件和选择，要等人还在那一处才发生。
  同一时刻只跟一处尚未落地的场景。
  章节由写作模块按已提交内容和离开处划分。写作模块每次只读当前这一处和下一处的开头。
  这一处还没有形成阅读弧时不成章。没有决定的思考不进入正文。同一条调度链不会被拆开。
  双方都有原话的章节直接装配这些话。场景规格句不进入正文。
- 角色提示由系统生成，但分成志向、行事方式、眼前这一手。本地 NPC 说过这一层之后，
  感知要求离开，不再问第二遍。裁决器能看见相邻通路；离开必须落在这些地点上。

## 3. 已知缺口

### P0：阻碍“可追更”的质量问题

- 模型角色仍可能以不同措辞重复低价值核验；场景共享最近公共回合、待回应
  交流和外部异变已实现，但仍需多 seed 长跑验证；
- 新路径的自由意图避免了同批 opportunity 争用，却把质量压力转移到世界裁决：
  所有跨场景移动和物件持有变化都必须有结构化补丁，不能只存在于文字结果；
- Soul 演化在中程运行中仍偏快；
- 内容分章已经接上，但非对白章节仍可能走文学管线并回退。回退正文不能露出实体编号，也不能把同一句说两遍。焦点与因果链选择仍较基础；
- 文学门禁以来源、时序、引语、隐私、段落形态和 UserGate 隔离为主；已移除
  中文动作/同义词黑名单，避免用词表假装修复叙事结构；
- 确定性回退已从逐事件模板改为场景化事实梗概，但不会虚构感官细节或心理，
  因而不能代替模型主 Renderer 的文学成稿；
- seed 17 第六轮已闭合白灵持铃、悟空持拨火铁棍及其进入侧殿的权威状态；
  第 27 轮重策展进一步把 23 个来源压成四段，建立段、物件冲突和逆风铃转折
  均可读。严格连续性评审为 69/80、无硬伤，文学评审为 49/80，仍未达到
  56/80 技术门槛，更不应宣称达到专业作家终态；
- 当前文学瓶颈已经从“日志转写”收敛为世界事件本身缺少完整的
  目标—阻力—决定—后果闭环；本轮已加入世界终局问题、角色动机/承诺、
  场景阶段问题、拖延压力和可观察收束信号；
- ExperienceContract 已使 Runtime 只读通用压力/收束参数，Presentation 只读
  Episode/Skill/Voice/角色声音；这证明换世界可由配置替换，不证明类型承诺已在
  多 seed 长运行中稳定兑现；
- 场景裁决记录 `none / advance / decision / resolved`。连续无进展会提高压力。
  压力达到高位后，这一手要给出离开、交出、留下或拒绝的公开决定。在场角色都提交
  决定时可以形成集体阶段结果。`resolved` 只结束这一处的内部节拍，不直接切章。
  离开当前地点走相邻通路，不要求先把场景标成 resolved；
- seed 83 长篇验证在 Tick 54 发布 20 章，覆盖 6 个地点、12 个场景，14 次
  跨地点迁移、1 次回访，位置同步与 replay 均通过；当前文学回退为 1/20
  （5%），不代表专业长篇质量已经达标，详见
  [长篇自主世界验证 v1](../experiments/longform-autonomous-world-v1.md)；
- seed 17 的动机纵切第四轮在 Tick 2 形成三名完整角色的公开承诺并关闭阶段
  问题；10 Tick 仅产生 10 个 `TURN_RESOLVED`、11 次模型调用。没有强制承诺的
  第二轮产生 52 个回合和 56 次调用且仍未收束，证明收束来自动机/压力状态机，
  不是固定 Tick。该结果只覆盖一个 seed，仍需多 seed 验证；
- 模型 Renderer 只接收策展后的最小事实视图，不再把组件中的 `recent_turns`
  历史泄漏给写作模型；直接引语按不同角色抽取承重短句，无主体的用户干预
  不得被归给角色；
- `bank-the-embers` 与 `leave-the-dark` 已产生不同资源、位置、事件数量和
  剧情观察结果，证明用户选择形成真实分支，而不是只改末尾文案。
- 世界运行与文学编辑现已成为两条独立生命周期。presentation workflow 的
  `curate / plan / render / validate` 不再空转；render 依次执行四个宿主
  `SKILL.md`：发展编辑、场景写作、行文编辑、事实连续性编辑，并保存 typed
  中间稿和逐阶段诊断。
- 固定 Digest 纵切位于 `outputs/literary-skill-iteration/`。第 7 轮复制
  `round-04-deepseek` 的 21 个来源，未推进世界，以 5 次 DeepSeek 调用通过
  自动事实与行文门禁；第 6 轮的无来源改写引语被具体诊断并确定性回退，证明
  阶段失败不会污染发布文本。
- 第 7 轮匿名八维评审为 58/80，超过 56/80 技术线，但旧基线同次评审为 60/80；
  新稿改善了孙悟空参与和三方交接，仍有解释性台词、信息偏密及结尾余味不足。
  因此 Skill 管线为 **verified**，文学质量仍不是 **quality-validated**，更未
  达专业发表标准。
- 机制优先质量循环位于 `outputs/quality-loop/`。规范物件、无进展回合过滤、
  戏剧功能策展、引语权限、保管链压缩、NPC 本地见闻和通用场景收束均已验证；
  最佳候选 `round-10-candidate` 匿名评审为 62/80，胜过同轮旧基线 51/80，
  但未达到 64/80，且后续 seed 仍会回落，说明质量尚不稳定。

旧路径样本位于 `outputs/literary-iteration/`；新实体场景迭代位于
`outputs/entity-scene-iteration/`，当前事实连续性基线是
`round-27-rerender`；`round-21-deepseek` 是延长至 8 Tick 后仍重复查验的
反例证据。
动机与场景压力纵切位于 `outputs/dramatic-motivation-iteration/`；
`round-02-deepseek` 是只有压力、缺少强制承诺时的未收束反例，

## 4. 下一阶段工作流

下一阶段不继续堆叠横向能力，而按质量闭环推进。

### Q1：行为可信度

目标：角色行动看起来有理由，世界不靠随机移动制造活跃。

退出条件：

- 40 Tick 内无明显无目的往返；
- 对话关联具体事实并受主题冷却；
- 角色长期变化有跨 Tick 证据；
- action rejection 比例进入预设合理区间；
- 两个世界、多 seed 均未退化。

### Q2：剧情策展

目标：把连续历史分成可读、可追溯、值得追更的 Episode。

状态：内容分章和已提交对白装配已实现。文字质量仍要单独评审，不能用章节数量代替。

退出条件：

- 内部调度事件不进入正文；
- 每篇围绕有限窗口和一条主因果链；
- 重复移动和等待被压缩；
- 关键事实完整且全部可追溯；
- 人工评审不再把正文主要评价为流水账。

### Q3：长期连续性

目标：世界运行 100 Tick 以上仍能保持角色、关系、资源和未决事项的连续性。

退出条件：

- 100 Tick 多 seed soak 可 replay、可解释且无失控增长；
- Episode 间能延续并关闭线索；
- 冷热切换不制造知识、关系或人格跳变；
- Avatar 中途加入后能形成有意义历史分叉。

### Q4：创作闭环

目标：让没有游戏设计经验的用户通过 Agent 和可视化反馈完成一个小世界。

退出条件：

- 从自然语言草图生成合法目录世界包；
- 用户能看到规则变化对模拟的影响；
- revision、锁定区、fork 和失败诊断可理解；
- 至少一名外部创作者无需修改引擎代码即可完成并发布世界。

## 5. 当前不应做

- 在行为和策展质量未稳定前扩建大型《西游后传》内容；
- 用更强模型掩盖错误的事实选择或重复机制；
- 把当前四类 Workflow 描述为任意 DSL；
- 为单个世界引入执行器专名分支；
- 以 M0–M7 完成、测试数量或事件数量宣称产品完成；
- 同时大改世界格式、运行机制和叙事策略，导致结果不可归因。

## 6. 状态更新规则

每次阶段变化时只更新本文件的当前判断、证据和优先级；历史里程碑保留在最终报告。状态声明必须区分：

- **implemented**：代码路径存在；
- **verified**：自动化或可复现实验证明契约；
- **quality-validated**：多 seed 和人工评审达到质量线；
- **user-validated**：真实目标用户实验达到指标。

没有达到后一层时，不得用前一层结果代替。
