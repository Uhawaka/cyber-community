# 当前版本状态

## 主链

统一作者源 → 唯一 v1alpha3 社区包 → CLI / 组合根 →
托管社区 Tick → 本人认知与决策 → 注册行动、世界与社会结算 →
原子事件日志 → 恢复与只读观察。

调用关系见[当前版本结构](../architecture/project-structure.md)，使用方式见
[运行指南](../authoring/community-runtime.md)。

- 只维护社区入口；旧场景、导演、Avatar、冷热模拟和文学发布执行链已退役。
- 移除 v1alpha2 编译分支、旧兼容转发、旧策略装配与旧记忆投影。

  持久化、安全、工作流校验和模型装配验证保留在当前社区测试中。
- 正式世界为回声码头、石阶院、黑松岭、青衡院、李氏族院、黑风寨及对应统一作者源。
  中间修订和旧世界夹具不参与当前编译或测试。
- 世界 hash 包含完整编译内容；托管运行绑定引擎指纹，旧日志不能续跑当前代码。
- 修复假值策略被静默忽略；探针默认单个 20 Tick 样本，盲评不强制扩 seed。

## 当前验证

- 最终完整回归：1002 项通过，零失败、零跳过，包含旧入口不得恢复的架构保护。
- 新建石阶院 DeepSeek 单样本：20 Tick、68 次请求，六项机制门禁通过。
  一次 SSL 连接中断被持久化为失败响应，未自动重试；恢复、重放、来源、
  库存与请求记录校验通过。报告在 `outputs/experiments/`。
- 六套正式世界由统一作者源可重复构建；当前源码无孤立生产 Python 模块。

这些结果证明当前机制和恢复边界，不代表人物或剧情质量验收。
